Создай полностью рабочую 2D-игру для Unity 6.3 на C#.

Это бесконечный 2D clicker / boss-rush про кражу времени.

Целевая платформа:
- Unity 6.3
- WebGL
- Яндекс Игры
- мышь
- тачскрин

Целевая аудитория:
примерно 6–12 лет.

Главные требования:

- управление должно быть понятно почти сразу;
- яркий дружелюбный мультяшный дизайн;
- минимум перегруженных меню;
- противник всегда является главным объектом экрана;
- игрок нажимает непосредственно по врагу;
- никаких отдельных кнопок "АТАКОВАТЬ";
- игра бесконечная;
- код должен быть понятен начинающему разработчику;
- Unity UI + TextMeshPro;
- никаких обязательных сторонних плагинов;
- игра должна работать даже если музыка, звуки или некоторые эффекты пока не назначены;
- не должно быть NullReferenceException из-за пустых необязательных AudioClip;
- не переписывать уже рабочие системы без необходимости.

==================================================
1. ГЛАВНАЯ ИДЕЯ
==================================================

Игрок проходит бесконечные уровни:

1
2
3
4
5
...

На каждом уровне появляется враг.

У игрока есть собственный запас времени.

У врага тоже есть запас времени.

Время — это одновременно здоровье.

Во время боя время игрока постоянно уменьшается само по себе.

Например:

PlayerTime -= Time.deltaTime;

Если время игрока становится 0:

ИГРА ОКОНЧЕНА.

Игрок крадёт время у врага.

Когда игрок атакует:

EnemyTime уменьшается.

PlayerTime увеличивается на реально украденное количество времени.

Когда EnemyTime становится 0:

враг побеждён.

==================================================
2. МАКСИМАЛЬНОЕ ВРЕМЯ
==================================================

У игрока есть:

CurrentTime
MaxTime

Например:

12 / 20 сек

Игрок не может накопить больше MaxTime.

Пример:

CurrentTime = 19.9
MaxTime = 20

Атака должна украсть:

0.5 сек

Но игрок может принять только:

0.1 сек

Необходимо корректно ограничивать полученное время.

Внутренние расчёты делать через float.

Но игроку НЕ показывать:

12.372 сек

На UI показывать только целые секунды:

Mathf.CeilToInt(CurrentTime)

Например:

12 / 20 сек

3. СТАРТОВЫЕ ХАРАКТЕРИСТИКИ
==================================================

Для первоначального баланса использовать примерно:

MaxTime = 5

CurrentTime = 5

Attack = 1.0

CritChance = 5%

CritMultiplier = 2.0

Armor = 0

MagicResistance = 0

Все значения должны легко редактироваться через Inspector.

==================================================
4. ХАРАКТЕРИСТИКИ ИГРОКА
==================================================

У игрока ровно шесть основных характеристик:

1. MAX TIME / МАКС. ВРЕМЯ

Максимальное количество времени игрока.

--------------------------------

2. ATTACK / АТАКА

Определяет основную силу кражи времени.

Attack влияет и на физическую, и на магическую атаку, но у этих двух типов атак разные базовые коэффициенты.

Не создавать отдельную характеристику Magic Attack на данном этапе.

--------------------------------

3. CRIT CHANCE / ШАНС КРИТА

Шанс критического физического удара.

Например:

12%

--------------------------------

4. CRIT MULTIPLIER / МНОЖИТЕЛЬ КРИТА

Например:

x2.1

Если обычная физическая атака украла бы:

0.5 сек

то крит при x2:

1.0 сек

Криты по умолчанию относятся только к физическим атакам.

--------------------------------

5. ARMOR / БРОНЯ

Защита от физических атак врагов.

--------------------------------

6. MAGIC RESISTANCE / СОПРОТИВЛЕНИЕ МАГИИ

Защита от магических атак врагов.

==================================================
5. ДВА СПОСОБА АТАКИ ИГРОКА
==================================================

Игрок взаимодействует непосредственно со Sprite врага.

Никаких кнопок:

"ФИЗИЧЕСКАЯ АТАКА"

или

"МАГИЯ"

на боевом экране нет.

Используется одно естественное управление.

--------------------------------
КОРОТКОЕ НАЖАТИЕ
--------------------------------

Короткий tap / click:

ФИЗИЧЕСКАЯ АТАКА.

Игрок нажимает по монстру:

→ происходит один физический удар;
→ EnemyTime уменьшается;
→ реально украденное время добавляется игроку.

Физическая сила зависит от Attack.

Пример формулы:

PhysicalSteal =
BasePhysicalSteal * Attack

Все коэффициенты редактируются через Inspector.

--------------------------------
УДЕРЖИВАНИЕ
--------------------------------

Если игрок зажимает врага:

МАГИЧЕСКАЯ АТАКА.

После небольшой задержки начинается непрерывное высасывание времени.

Например:

HoldThreshold = 0.25 сек

Если пользователь отпустил раньше:

считается физический клик.

Если продолжил держать:

физический удар не происходит,
начинается магическая атака.

Пока удерживание продолжается:

EnemyTime постоянно уменьшается.

PlayerTime увеличивается.

Например:

MagicStealPerSecond =
BaseMagicSteal * Attack

Магическая атака должна считать результат с помощью Time.deltaTime.

==================================================
6. TOUCH И MOUSE
==================================================

Система должна одинаково работать:

- мышью;
- одним пальцем.

Не использовать OnMouseDown как основную систему.

Использовать Unity EventSystem:

IPointerDownHandler
IPointerUpHandler

при необходимости:

IPointerExitHandler

Нужно надёжно различать:

Tap

и

Hold.

Если игрок начал hold, отпускание не должно дополнительно вызывать физический удар.

==================================================
7. ВИЗУАЛЬНОЕ ОТЛИЧИЕ ФИЗИКИ И МАГИИ
==================================================

ФИЗИЧЕСКАЯ АТАКА:

- быстрый squash врага;
- маленькая звёздочка;
- короткий "pop";
- floating text вроде "-1";
- при крите крупнее эффект;
- надпись "КРИТ!".

МАГИЧЕСКАЯ АТАКА:

- мягкий светящийся поток;
- маленькие частицы времени летят от врага к игроку;
- враг слегка дрожит;
- эффект продолжается, пока игрок держит палец.

Без тяжёлых 3D-эффектов.

==================================================
8. ВРАГИ БЬЮТ В ОТВЕТ
==================================================

Почти все враги активно атакуют игрока.

Враг не является просто мешком времени.

У каждого есть:

AttackType
AttackPower
AttackCooldown

Большинство врагов используют либо:

Physical

либо:

Magic.

Редкие враги могут не атаковать вообще, но это исключение.

==================================================
9. КУЛДАУН ВРАГА
==================================================

Каждый враг атакует с определённым интервалом.

Например:

AttackCooldown = 3 сек

После атаки кулдаун начинается заново.

AttackCooldown зависит от:

- базового типа врага;
- уровня;
- модификаторов;
- уникальной способности.

Не позволять кулдауну становиться слишком маленьким.

Например:

MinimumAttackCooldown = 0.8 сек

==================================================
10. ВРАГ ТОЖЕ КРАДЁТ ВРЕМЯ
==================================================

Когда враг атакует игрока:

PlayerTime уменьшается.

Украденное количество времени добавляется EnemyTime.

Например:

Игрок:

10 / 20 сек

Враг:

15 / 25 сек

Враг украл:

2 сек

После атаки:

Игрок:

8 / 20 сек

Враг:

17 / 25 сек

EnemyTime не может превышать EnemyMaxTime.

То есть бой представляет собой перетягивание времени между двумя сторонами.

==================================================
11. ФИЗИЧЕСКИЕ АТАКИ ВРАГОВ
==================================================

Если EnemyAttackType = Physical:

атака уменьшается бронёй игрока.

Использовать формулу с diminishing returns.

Например:

PhysicalReduction =
Armor / (Armor + ArmorConstant)

FinalDamage =
BaseDamage * (1 - PhysicalReduction)

ArmorConstant должен быть редактируемым.

Броня никогда не должна случайно создавать отрицательный урон.

==================================================
12. МАГИЧЕСКИЕ АТАКИ ВРАГОВ
==================================================

Если EnemyAttackType = Magic:

использовать MagicResistance.

Например:

MagicReduction =
MagicResistance /
(MagicResistance + MagicResistanceConstant)

FinalDamage =
BaseDamage * (1 - MagicReduction)

==================================================
13. ПОДГОТОВКА АТАКИ ВРАГА
==================================================

Для детской аудитории атаки не должны происходить абсолютно неожиданно.

Перед ударом сделать Telegraph.

Например:

0.3–0.7 секунды.

Физическая атака:

над врагом появляется маленький значок:

⚔

Враг немного отклоняется назад.

Затем делает рывок.

Магическая атака:

значок:

✨

Враг начинает светиться.

После этого происходит магический удар.

23. НЕСПРАВЕДЛИВЫЕ КОМБИНАЦИИ ЗАПРЕЩЕНЫ
==================================================

Процедурная генерация не должна создавать невозможного врага.

Нельзя одновременно выдавать:

полный иммунитет к физике

и

полный иммунитет к магии.

Если физическая защита очень высокая:

магическая защита должна быть меньше.

Если враг очень быстрый:

его AttackPower уменьшается.

Если враг имеет огромный EnemyMaxTime:

другие характеристики немного слабее.

но не должны радикально отличаться по реальной сложности.

29. ПОБЕДА НАД ВРАГОМ
==================================================

Игровой input на враге отключается.

Игрок должен чувствовать постепенное развитие,

НАГРАДА МИНИ-БОССА!

Мини-босс выдаёт одно хорошее случайное улучшение одной из шести характеристик.

или

Каждая карта предлагает улучшение одной характеристики.

[ +5 MAX TIME ]

[ +20% ATTACK ]

Карты исчезают.

Открывается обычный экран результатов.

==================================================

VFX

Просто пропускать их.

76. ГЛАВНАЯ ЦЕЛЬ MVP
==================================================

В результате нужен полностью играбельный прототип:

- бесконечные уровни;
- время постоянно заканчивается;
- MaxTime;
- физические атаки через tap;
- магия через hold;
- враги отвечают;
- физические и магические атаки врагов;
- Armor;
- MagicResistance;
- CritChance;
- CritMultiplier;
- Attack;
- процедурные обычные враги;
- процедурные Modifier;
- мини-босс каждые 10 уровней;
- босс каждые 25;
- 10 заранее подготовленных BossData;
- процедурные боссы после 250;
- маленький рост всех статов;
- хорошие награды с мини-боссов;
- выбор 1 из 3 лучших улучшений с босса;
- отдельное окно Stats;
- отдельный Shop;
- MaxTime и Attack в магазине;
- временные Buff;
- Осколки Времени;
- ContinueButton сбоку;
- защита от случайных кликов;
- музыка обычных боёв;
- отдельный музыкальный слот для каждого из 10 боссов;
- Crossfade Normal ↔ Boss;
- вся музыка необязательна;
- Game Over;
- BestLevel;
- простой яркий дизайн для детей 6–12 лет;
- WebGL-ready проект.
