# Вор времени — работа с проектом

Проект Unity: `D:\Game\TimeThief\game`. Редактор: **6000.3.23f1** с WebGL Build Support.

1. В Unity Hub выберите «Добавить проект с диска» и папку `game`.
2. Откройте `Assets/TimeThief/Scenes/Main.unity` и нажмите Play. Если сцена ещё не подготовлена, выполните **Time Thief → Prepare Project**.
3. Все ссылки, десять BossData, шрифт с кириллицей и спрайты подготавливаются автоматически. При каждом запуске заново собирать Hierarchy вручную не нужно.

## Где менять игру

`Assets/TimeThief/Resources/GameConfig.asset` — начальные шесть характеристик, Player Recovery Fraction (0,6), Same Type Resistance (0,9), Continuous Drain (1 сек/с), коэффициенты кражи, порог удерживания, рост врагов, естественная прогрессия, музыкальные и звуковые слоты. Значения редактируются через Inspector. Базовые время/сила всех врагов, включая боссов, рассчитываются одной строго возрастающей формулой. Особенности боссов задаются способностями.

`Resources/Enemies` — 16 визуальных шаблонов. Enemy Sprite можно заменить собственным PNG с прозрачностью; Texture Type должен быть Sprite (2D and UI).

`Resources/Bosses/Boss01.asset` … `Boss10.asset` — боссы уровней 25…250. Здесь настраиваются русское/английское имя, короткая подсказка, Sprite, музыка, тип атаки, способность, её параметры и множитель награды. После уровня 250 используются усиленные процедурные сочетания этих шаблонов.

По последнему запросу владельца созданы три мелодии и 12 коротких эффектов. У GameConfig назначены Menu Music, Normal Battle Music и Procedural Boss Music; у всех BossData назначен Boss Music. MusicManager использует два AudioSource с crossfade 1,5 секунды. При пустой музыке босса остаётся обычный трек; пустые звуковые слоты безопасны. Подробности и исходник синтеза — [AUDIO_RU.md](AUDIO_RU.md).

**Prepare Project** создаёт исходный комплект контента и обновляет его именованные поля и аудио. После своих правок используйте обычную сборку Unity через Build Profiles или `tools/build.ps1`, чтобы сохранить параметры контента. Скрипты и SVG изменять для замены аудио не требуется.

## Как играть

- Коротко нажмите на хранителя: физическая кража, возможен крит.
- Удерживайте 0,25 секунды: начинается непрерывная магия. Отпускание после удерживания не добавляет физический удар.
- Время игрока уменьшается только в активном бою. 60% фактического урона возвращается игроку до максимума. Противник получает всё потерянное игроком время, даже сверх своего начального запаса. Избыток не переполняет запас.
- Противник готовит ответный удар за 0,6 секунды. Физику уменьшает броня, магию — сопротивление магии.
- После победы часы стоят. Открывайте статы, магазин или продолжайте кнопкой в правом нижнем углу. Она защищена от остаточных кликов.
- Каждый 10-й уровень — мини-босс, каждый 25-й — босс. При совпадении босс имеет приоритет.
- Мини-босс автоматически даёт улучшение; босс предлагает три разных карты, выбрать можно одну.
- Магазин принимает осколки времени. Постоянно покупаются только максимум времени и атака. Ещё семь товаров — усиления на 1–3 боя.
- При полном поражении можно начать новый забег; рекорд и общая статистика сохраняются. При доступном SDK один раз за забег предлагается добровольное возрождение за рекламу.

## Сохранение

Сохраняются рекорд, общие победы и текущий забег: характеристики, осколки, покупки, оставшиеся бои усилений, время врага, кулдаун, фаза боя и выбор награды. Загрузка сохранённого боя открывает спокойное интро; таймер не идёт до кнопки «В бой».

В WebGL используется PlayerPrefs и дублирование JSON в localStorage. При доступном SDK — облачные данные игрока. Новейшее сохранение выбирается по времени записи. В редакторе JSON хранится в `D:\Game\TimeThief\LocalData`, а не на диске C. Новый забег требует подтверждения на главном экране, если есть сохранённый.

## Структура кода

GameManager управляет состояниями. PlayerStats отвечает за запас времени и защиты. EnemyGenerator формирует встречу по уровню и seed; EnemyController исполняет атаки и способности. EnemyInput различает tap/hold и сбрасывается при паузе, уходе указателя и смене экрана. RewardManager и ShopManager отвечают за рост и покупки. UIManager строит адаптивные экраны Unity UI + TextMeshPro. SaveManager и PlatformBridge отвечают за сохранение и Яндекс SDK. MusicManager безопасен при пустых AudioClip.

Старое ядро `Assets/_Project` и ранняя документация сохранены для истории, но не участвуют в новой сцене. Валюта новой игры — осколки, а не время здоровья из раннего прототипа.

## Сборка

Автоматически: `powershell -ExecutionPolicy Bypass -File D:\Game\TimeThief\tools\build.ps1`.

Скрипт использует D для TEMP/TMP, UPM, Emscripten, .NET, NuGet и логов. Уже установленная Unity, Windows и служба лицензирования могут вести собственные системные журналы; они не являются папками проекта. Unity Hub и редактор должны работать с одинаковыми обычными правами, чтобы подключаться к одной службе лицензирования.

Результат успешной сборки: `Builds/WebGL/index.html`, `Build/`, SDK-мост и иконка. Локальная проверка: `node tools/serve.cjs`, затем `http://127.0.0.1:8080`. Открытие index.html двойным кликом через file:// для WebGL не подходит.

**Time Thief → Run Core Checks** проверяет генерацию 4400 встреч, высокие уровни, ограничения времени, магазин, длительность усилений и три карты боссов. `node tools/test-sdk.cjs` проверяет рекламу и паузы без настоящих показов.

Векторные исходники: `assets/vector`. Персонажи и логотип: `assets/raster`, промпты: `assets/prompts`. Это сгенерированные встроенным imagegen PNG с альфа-каналом. Unity импортирует обычных персонажей до 512 px, боссов и Маятницу до 1024 px, с mipmaps и trilinear-фильтрацией. SVG используются для собственных иконок и рамок. `tools/art.cjs` и `tools/boss-art.cjs` сохраняют приоритет готовых PNG; `tools/ui-art.cjs` обновляет оформление. Nunito и Alegreya SC распространяются по SIL OFL, лицензии рядом с TTF.


## Баланс и проверки MVP

GameConfig содержит minimumTapInterval, bossPhaseRecoveryFactor, timePressure/timeCurve, powerPressure/powerCurve и cooldownPressure. Изменяйте их в Inspector и выполняйте обычную Build, сохраняя свои параметры. Метод Prepare обновляет поставляемый контент и импорты, поэтому нужен при восстановлении проекта или добавлении ресурсов.

`tools/model-checks.ps1` воспроизводит portable-проверки и 48 симуляций без Unity UI. Браузерные сценарии: `tools/browser-checks.cjs`, `browser-layout.cjs`, `browser-experience.cjs`, `browser-touch.cjs`, `browser-platform.cjs`, `browser-mvp.cjs`. Они используют настоящий WebGL и изолированные сохранения браузера. Упаковка проверяется `tools/verify-release.py`.
