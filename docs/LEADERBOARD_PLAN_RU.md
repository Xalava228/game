# Рейтинг на главном экране

В UIManager выделен метод MenuRecords и отдельный контейнер MenuRecords. Сейчас там настоящий рекорд забега и общее количество побеждённых боссов. Он не имитирует сетевой рейтинг. Блок можно заменить входом в таблицу без перемещения названия, иллюстрации и кнопок запуска; на телефоне таблица открывается отдельным окном.

Следующее подключение потребует реального имени лидерборда из консоли Яндекс Игр. Предлагаемый показатель: максимальный достигнутый уровень, больше — лучше. Публиковать только улучшенный рекорд; запросы таблицы — по нажатию, с кешем. Доступность записи проверять через isAvailableMethod; запрос авторизации, если потребуется, показывать только по действию игрока. Ошибка сети не должна блокировать гостевой забег. Имя игрока выводить как обычный текст, без rich text.

Официальные методы и ограничения: [лидерборды Yandex SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-leaderboard), проверено 10.09.2026. Имя лидерборда и серверные настройки пока не задавались; фиктивные места и игроки в игру не добавлялись.
