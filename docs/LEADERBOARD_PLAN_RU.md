# Подключение таблицы лидеров — 1.6.0

Кнопка находится в главном меню. В Unity реализован отдельный экран с личным рекордом и ответами SDK. Без доступной таблицы показывается сообщение о недоступности общего рейтинга. Вымышленных игроков в рабочей сборке нет.

Создайте в консоли Яндекс Игр числовую таблицу: ноль десятичных знаков, сортировка по убыванию. Показатель — максимальный достигнутый уровень. Точное техническое название укажите в game/Assets/WebGLTemplates/TimeThief/platform-config.js, поле leaderboardName. Сейчас оно пустое: имя из консоли ещё не передано.

В готовой сборке можно изменить тот же файл в Builds/WebGL и повторить упаковку. Чтобы настройка сохранялась при последующих сборках, измените также исходный шаблон. Перекомпилировать Unity ради этого поля не требуется.

Используются актуальные методы ysdk.leaderboards.getEntries, getPlayerEntry и setScore. Перед отправкой проверяется isAvailableMethod('leaderboards.setScore'); диалог входа автоматически не открывается. При открытии таблицы публикуется только результат выше серверного рекорда. Ошибка чтения собственного рекорда не приводит к его перезаписи. Гость может читать публичный топ. Ответ кешируется 30 секунд, запросы ограничены таймаутами. Имена ограничены по длине, TMP rich text отключён.

Автоматические тесты используют test-board только в изолированной подмене SDK. Это не название рабочей таблицы.

Источник: [SDK Яндекс Игр — лидерборды](https://yandex.ru/dev/games/doc/ru/sdk/sdk-leaderboard), проверено 13.09.2026.
