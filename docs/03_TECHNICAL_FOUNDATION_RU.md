# Техническая основа TIME/DEBT

## Зафиксированная версия

**Unity 6.3 LTS, редактор 6000.3.22f1, changeset 1c726e1fb402.**

Выбрана LTS-ветка, потому что проект только начинает долгий цикл разработки. Точная patch-версия записана в `ProjectSettings/ProjectVersion.txt`: у всей команды и CI будет одинаковый редактор без случайных миграций проекта.

## Первая платформа и формат

- горизонтальный экран 16:9;
- PC как основная платформа для итераций;
- WebGL как удобный канал для быстрых тестовых билдов;
- управление мышью, с дальнейшим добавлением клавиатуры и accessibility-режимов.

## Первый вертикальный срез

1. Игрок начинает бой с 60 секундами жизни.
2. Баланс уменьшается в реальном времени.
3. Каждый осмысленный клик крадёт 0,5 секунды у Талонника и передаёт её игроку.
4. Ноль на таймере любой стороны завершает бой.
5. Между боями игрок может купить усиление, буквально сократив оставшуюся жизнь.

Этот контур уже выражен классами `TimeBalance` и `TimePrototypeController`. Следующий кодовый шаг — отделить настройки врагов в ScriptableObject, собрать UI таймера и добавить анти-автоклик-паттерны, уникальные для каждого противника.

## Технические принципы

- время хранится как число секунд с дробной частью;
- операции перевода централизованы, чтобы избежать расхождения UI и экономики;
- баланс никогда не становится отрицательным;
- покупка может требовать несгораемый резерв, чтобы случайный клик в магазине не убивал игрока;
- игровые правила отделяются от визуала — это позволит быстро тестировать баланс без полной графики.
