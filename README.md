# TIME/DEBT

Новый 2D clicker/idle-проект на стадии препродакшена и первого технического прототипа.

## Текущее ядро

Время персонажа одновременно является его здоровьем и единственной главной валютой. В бою игрок переводит время от врага себе, а между боями добровольно сжигает часть собственной жизни ради усилений.

Рекомендованная арт-дирекция: **хронобиологический бюрократический гротеск** — мир учёта, кредитов и конфискации будущего, где тела срастаются с талонами, печатями, табельными аппаратами и живыми хранилищами времени.

## Техническая основа

- **Unity 6.3 LTS — 6000.3.22f1** (`1c726e1fb402`)
- горизонтальный формат 16:9, PC/Web как первая цель;
- Unity-проект находится в [`game/`](game/);
- стартовое runtime-ядро уже моделирует постоянное сгорание времени, кражу времени кликом и покупку улучшений из того же баланса.

Почему LTS: это последний патч актуальной долгосрочно поддерживаемой ветки Unity 6.3. Для проекта с долгой разработкой важнее закрепить воспроизводимую стабильную версию, чем переходить на более быстро меняющуюся Update-ветку.

## Первый запуск

1. Установить Unity Hub и редактор **Unity 6000.3.22f1** с модулем WebGL Build Support.
2. В Unity Hub выбрать **Add project from disk** и указать папку `game`.
3. После первого импорта создать сцену в `Assets/_Project/Scenes` и добавить на объект компонент `TimePrototypeController`.
