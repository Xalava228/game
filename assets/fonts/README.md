# Nunito

The game uses the static **Nunito Bold** face so Unity's font importer does not select the ExtraLight master of the variable font. Nunito is distributed under the SIL Open Font License 1.1; see OFL.txt.

Source: [google/fonts, static Nunito Bold](https://github.com/google/fonts/blob/c7e2740188205a85323c7385547f6f59b4f2245a/ofl/nunito/Nunito-Bold.ttf).

The gameplay font atlas is generated by ProjectBuilder.Prepare and contains Latin, Cyrillic and the punctuation used by the UI. Cover artwork is rendered with the same static face.
