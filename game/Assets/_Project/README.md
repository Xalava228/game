# TIME/DEBT — Unity assets

Весь авторский контент проекта хранится внутри `_Project`, чтобы он не смешивался со сторонними пакетами.

- `Art/Concepts` — утверждённые и промежуточные концепты;
- `Scenes` — игровые сцены и тестовые песочницы;
- `Scripts/Runtime/Core` — независимое ядро экономики времени;
- дальнейшие папки: `Audio`, `Prefabs`, `UI`, `VFX`, `ScriptableObjects`.

Стартовая проверка: создать объект в пустой сцене, добавить `TimePrototypeController` и привязать UI-кнопку клика к публичному методу `TryStealFromEnemy`.
